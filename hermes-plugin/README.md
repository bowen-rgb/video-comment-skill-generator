# Hermes plugin bridge

Install this folder as:

    %LOCALAPPDATA%\hermes\plugins\video-comment-skill-generator\

Restart Hermes, then use:

    /video-comment status --run runs/BV1

The plugin executes the local generator without a shell. Browser collection remains visible-session work through Chrome DevTools MCP; the command bridge stores batches, enforces completeness, summarizes, and generates Skills.
